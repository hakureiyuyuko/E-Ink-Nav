# 帧协议

手机端与墨水屏端之间的数据通道，固定为**蓝牙 RFCOMM（标准 SPP UUID
`00001101-0000-1000-8000-00805F9B34FB`）**，无需配对，直连即可。
两端均不申请任何网络权限。

## 混合帧格式

一个连接上同时承载文本帧和图片帧，墨水屏端用首字节区分：

| 首字节 | 类型 | 结构 |
|---|---|---|
| `'{'` (0x7B) | 旧版行协议 | 直到 `\n` 为止的 UTF-8 JSON，兼容手工测试 |
| `0x01` | 图片帧 | `01` + 4 字节大端长度 + JPEG 字节 |
| `0x02` | 文本帧 | `02` + 4 字节大端长度 + UTF-8 JSON |

图片长度上限 6 MB，超长帧会被丢弃。

## 文本帧类型

### 旋转指令

```json
{"cmd":"rotate","deg":90}
```

`deg` 取值 `0` / `90` / `270`。墨水屏端收到后旋转整个画布（逻辑坐标 480×800 ↔ 800×480）。
墨水屏端另有自愈逻辑：根据收到图片的宽高比自行判断横竖，指令丢失也能摆正。

### 骑行数据（GPS）

```json
{"gps":1,"spd":23.7,"alt":86,"hdg":42,"acc":4}
```

| 字段 | 含义 | 单位 |
|---|---|---|
| `spd` | 速度 | km/h |
| `alt` | 海拔 | m |
| `hdg` | 航向角（0=北，顺时针） | 度 |
| `acc` | 定位精度 | m |

### 搜星状态

```json
{"gps":1,"wait":1,"ws":7}
```

`ws` 为已等待秒数。手机端在未获得定位时每 1.2 s 推一帧，墨水屏显示「正在搜索卫星… 已等待 N 秒」。

### 文字导航（早期模式）

```json
{"arrow":"right","dist":"300","unit":"米","road":"建国路","remain":"12.3 公里","eta":"15:20"}
```

`arrow` 取值：`left` `right` `straight` `slightleft` `slightright` `keepleft`
`keepright` `uturn` `roundabout` `arrive`。

### 心跳

```json
{"ping":1}
```

空闲 5 s 后发送，仅用于让对端知道连接存活。

## 图片帧约定

- 手机端输出分辨率为 **480×800（竖版）** 或 **800×480（横版）**，JPEG 质量 55–72
- 灰度（`ColorMatrix.setSaturation(0)`），便于单色墨水屏显示
- 墨水屏端会按字节比较去重：与上一帧完全相同的图片不重绘
